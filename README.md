В данной лабораторной работе №2 была оформлена HTMLстраница из ЛР №1 (с небольшими изменениями) с помощью внешнего CSS-файла style.css. 
Основной стиль вынесен во внешний файл, один элемент оформлен inline-стилем, а для маркированного списка навыков задано отдельное правило во внутреннем блоке. 
На странице показаны примеры позиционирования static, relative и absolute, а для ссылок реализованы состояния :hover, :active, :focus и :visited. 
Рядом с названиями проектов с помощью псевдоэлементов ::before и ::after добавлены «визуальные волны», которые при наведении меняют цвет и начинают дрожать (анимация shake), а при нажатии на кнопку она уменьшается на 2%.
