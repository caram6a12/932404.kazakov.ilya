# Лабораторная работа №3

**Вариант 9:** Музыкант и звукорежиссёр

## Описание

В данной лабораторной работе №3 я дополнил страницу из лабы 2 новыми блоками,
чтобы научиться делать адаптивные элементы на странице для удобства на любом экране.
(lab2.html->lab3.html, style.css дополнил в конце и добавил папку "фото" для обложек релизов и оборудования)

Для этого я использовал: Flexbox, который выстраивает элементы
в один ряд и сам решает, как их переносить, и CSS Grid, который раскладывает элементы
сразу по строкам и колонкам, а так же медиа-запросы, которые меняют вёрстку в зависимости от ширины экрана.

В шапке страницы появилось навигационное меню (на Flexbox) с тремя ссылками: «Релизы», «Оборудование» и «Связь».
Ниже добавил «Мои релизы» с четырьмя карточками, каждая имеет название, год выхода и жанр и фото-обложку. 
Карточки разложены через Flexbox: на компьютере их четыре в ряд, на планшете по 2, а на телефоне в столбик.

Дальше идёт секция «Студийное оборудование»: микрофон,
MIDI-клавиатура, аудиоинтерфейс, наушники, студийные мониторы и контроллер DAW.
У каждого блока есть фото, название и короткое назначение. 
Эта секция собрана на CSS Grid: на компьютере получается три колонки
и два ряда, на планшете две колонки, а на телефоне всё в один столбик.

Адаптивность сделана с помощью медиа-запросов. Когда ширина окна меньше 750 пикселей
(это примерно планшет), карточки встают по две, а оборудование в две колонки.
Когда ширина меньше 480 пикселей (телефон, на пк нельзя сделать настолько узкое окно браузера),
все блоки становятся в одну колонку, а пункты меню переносятся на новую строку.
