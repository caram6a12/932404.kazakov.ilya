# Лабораторная работа №1 — «О себе»

**Вариант 9:** Музыкант и звукорежиссёр

## Описание

В данной лабораторной работе была создана HTML страница «О себе», которая содержит следующие элементы: в шапке header указано имя и заголовок страницы, в основном контенте main размещена страница, всё вместе оформлено в тёмных сине-фиолетовых цветах. 
На странице представлены две смысловые секции «Навыки» с маркированным списком музыкальных навыков (игра на инструменте, знание DAW, сведение треков) и «Проекты» с нумерованным списком музыкальных работ (кавер-версии, собственные композиции, ремиксы, саунд-дизайн), ниже  aside с любимым инструментом. 
Добавлена фотография (с атрибутами src, alt, width, height) и форма обратной связи с полями «Имя», «Email» и «Сообщение», у каждого из которых заданы name и placeholder, и кнопка отправки.
В конце страницы подвал footer с копирайтом и годом, а также набор ссылок на социальные сети. Оформление через встроенный CSS.
