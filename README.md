# Лабораторная работа 5

**Вариант 9:** Музыкант и звукорежиссёр

## Описание

В данной лабораторной работе №5 я сделал плейлист треков (У каждого трека есть название, длительность, чекбокс «Избранное» и кнопка «Удалить») 
чтобы научиться работать с DOM-деревом и сохранять состояние между перезагрузками, а именно находить элементы страницы тремя способами: 
getElementById (по id), querySelector (по классу) и querySelectorAll (сразу все треки списка).

Ещё две кнопки меняют саму страницу: «Переключить тему» включает светлую тему, а «Скрыть плейлист» прячет список
и поля ввода. Кнопка при этом остаётся на месте и меняет надпись на «Показать плейлист».

Данные сохраняются в localStorage: треки (название,
длительность, избранное), выбранную тему и то, скрыт ли плейлист. Когда страница
загружается заново, скрипт читает эти данные и восстанавливает плейлист и тему
в том же виде.

Также добавил обработку ошибок: перед каждым действием скрипт проверяет, нашёлся ли
нужный элемент, и если чего-то нет пишет сообщение в консоль, а не ломается.
